# Start here

**Written for:** anyone putting the Human First AI name on something — organisers, volunteers,
designers, writers, partner agencies.

If you read one page, read this one.

## What we are

A global movement making AI usable by ordinary people. Free workshops, plain language,
tools for real life. 38 chapters.

**The line that decides everything:** *Make AI feel like an open door, not a locked lab.*

**The promise:** The future belongs to all of us.

## The five-second rules

1. **Human leads.** In the name, in the layout, in the sentence. Always.
2. **Plain words.** If a twelve-year-old cannot read it, rewrite it.
3. **Warm, not cold.** Cream paper and ink. Never black glass and cyan.
4. **It has to be readable.** Every pairing in this system is measured. Use the approved ones.
5. **Real people, real light.** No robots, no circuit boards, no glowing brains.

## Four checks before anything goes out

- [ ] Does it sound like a patient teacher, not a tech company?
- [ ] Is "Human" leading, visually and in the sentence?
- [ ] Does every piece of text clear 4.5:1 against what is behind it?
- [ ] Is there a real person in it, in real light?
